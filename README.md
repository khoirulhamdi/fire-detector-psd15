# FIRE DETECTOR | PSD-15
Aplikasi pemantauan kebakaran dini secara real-time melalui kamera langsung maupun unggahan foto. Sistem ini menggunakan metode MobileNet untuk mendeteksi kemunculan asap serta mengklasifikasikan skala titik api ke dalam beberapa kategori yaitu ada kecil, sedang, besar, dan sangat besar.
